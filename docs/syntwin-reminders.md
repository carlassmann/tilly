# Tilly reminder controls, birthdays and overdue reminders

Tilly lets you delete an individual reminder while keeping the person and all their notes. This also applies to a birthday reminder after someone dies: remove the reminder, not the person or memories. There is no per-person reminder pause or mute switch. Turning off repeat only stops future repeats; it does not delete the next scheduled occurrence. The visitor performs deletion themselves; the website guide can explain the controls.

If Tilly is not opened for a month, unfinished past-due reminders remain active until the user handles them. Tilly does not automatically clear old reminders or remove a backlog because of inactivity. The user can return whenever they wish; there is no required daily routine.

These are general Tilly product behaviors, not a reading of the visitor's own account. They can be explained without page access or sign-in.
