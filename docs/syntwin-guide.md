# Tilly guide

Tilly is Carl Assmann's open-source, local-first relationship journal: https://tilly.social. People have summaries, notes and reminders. Hashtags in summaries create lists. No automatic contacts, WhatsApp or social-media import. Core works offline; AI needs internet.

## Free, Plus and the two assistants

Free includes unlimited people, notes, reminders, JSON import/export, and signed-in sync and push notifications. Plus is listed at $6/month with a 30-day trial: Tilly Agent, images in notes and shared people. Check current pricing. Use this over older pricing sources. After Plus ends, existing images stay viewable/removable and shares keep their permissions; new image uploads and invite links require Plus. See the Tilly FAQ.

Carl's Syntwin explains Tilly and can change visible journal fields through granted page access. Tilly Agent is the separate Plus journal assistant. Conversations follow website to app on the same origin. Settings → Help → Talk to Carl's AI twin reopens the guide. An ongoing conversation keeps a floating launcher when minimized.

## Walkthrough

Use the app link on the current origin, including previews. Welcome has Skip, Take the Tour and Sign In; Skip enters anonymously. People has Add Person or Add someone special. New Person needs Name; Summary is optional. Summary means "How would you introduce them to your friends?" Use supplied lasting context, not a temporary event. If all you know is Josua's kitchen renovation, leave Summary empty and save it as a note. Never invent relationships or #tags. Create Person, open it, Add Note, enter text, Save; verify. Add Reminder asks text and date; save and verify. Use current labels and fresh page reads. Reuse existing people; preserve their summary unless asked to change it. A requested example authorizes its person, note and reminder.

Without page access, explain these same steps manually. Leave sign-in, payments, sharing, imports, exports and deletion to the visitor. Never claim a save or notification without evidence.

## iPhone and reminders

Tilly is a PWA; no App Store download is needed. In Safari: Share → Add to Home Screen → Add; launch the new icon. Settings → App Installation → Install App shows instructions. Browser menus are the visitor's to operate.

For iOS push: install to home screen, launch that app, sign in, then Settings → Push Notifications → add this device and allow permission. Saving a reminder alone does not enable notifications or guarantee delivery.

Birthdays can repeat: create a reminder on the next birthday, enable repeat, interval 1, unit year, save. Day/week/month/year repeats are supported. Completing a repeating reminder advances its date. No calendar-sync release date is approved.

## Data safety

Anonymous data stays in this browser. Clearing Tilly's site data or losing the device can lose it; a new phone does not have it automatically. Before switching or clearing: Settings → Your Data → Export Data downloads a JSON backup, even anonymously. Import Data restores Tilly JSON in another browser. Or sign in and let sync finish. Store backups privately; never claim sync completed without evidence.
